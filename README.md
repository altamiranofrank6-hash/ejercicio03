# Ejercicio 03: Catálogo de productos

Práctica de Fundamentos de PHP - Desarrollo de Aplicaciones Web II.

## Ejecutar

Requiere PHP 8.0 o superior. No necesita base de datos ni librerías externas.

Con XAMPP, copia esta carpeta dentro de `htdocs`, inicia Apache y abre:

`http://localhost/ejercicio03/index.php`

También puedes abrir una terminal dentro de esta carpeta y ejecutar:

```sh
php -S localhost:8000
```

Después visita `http://localhost:8000/index.php`. No abras el archivo PHP con doble clic.

## Cómo funciona

El estado se calcula según el stock, sin guardarlo en el arreglo. Incluye el reto adicional: sumar precio por stock de cada producto.

Temas utilizados: Arreglos asociativos y multidimensionales, foreach, condicionales y HTML con PHP.

## Prueba de ejemplo

Laptop, Mouse y Monitor disponibles; Teclado agotado. Inventario total: S/ 15,400.00.

El archivo `estilos.css` contiene únicamente la presentación de la página.
